# Real-Time Low-Light Image Enhancement

A computer vision project for enhancing low-light images using:

- Histogram Equalization
- CLAHE
- Gamma Correction
- Handcrafted Zero-DCE
- Neural Zero-DCE

## Features

- Upload image
- Select enhancement model
- Real-time inference
- Compare input/output
- Download enhanced image

## Tech Stack

- Python
- OpenCV
- PyTorch
- Streamlit
